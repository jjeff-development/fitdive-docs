Importing from a Garmin export

Every import starts from a Garmin .fit file - whether it's one dive shared straight from the Garmin Dive app, or hundreds of them from a full Garmin Connect data export. Here's what FitDive does with the file itself, separate from how it checks the result against your MySSI logbook.

Finding the dive site

Your Garmin dive computer records a GPS fix when it can get one - usually only on the surface, before you descend or after you surface. FitDive reads that fix (or falls back to your phone's current location, or a fallback site you set once in Settings, if the file has none) and searches MySSI's own dive-site database within a radius around it.

If more than one site turns up nearby, FitDive shows you the list and asks - it never silently guesses between two real candidates.

Entry point vs. exit point. Some dive computers only get a GPS lock after you're back on the surface at the end of the dive - which can be a genuinely different spot from where you entered, especially on a drift dive. FitDive reads both fixes from the file separately. When you add a new private dive site, you can pick the entry point, the exit point, or your phone's current GPS, and drag the pin from there - see Private Sites for what that screen looks like.

Private dive sites

MySSI's own site search only ever returns public listings - it can't find a private site you've already created, even one of your own. FitDive works around this by remembering every private site you create (and caching its MySSI-reported dive count) so it's reusable the next time you dive there, without you needing to search for it first.

Importing your whole Garmin history

If you've been diving with a Garmin computer longer than you've had FitDive, you don't have to share each dive in one at a time. Request a full data export from Garmin Connect's data management page - it can take Garmin a little while to prepare and email you the download.

Once you have it, open Import Garmin History on FitDive's home screen and pick the export file. FitDive scans every dive inside it in one pass and checks each one against your MySSI logbook exactly as described in how dive matching works - so you get a single list showing what's already logged, what's a possible match worth a second look, and what's still missing, even for dives from years before you had the app.

From that list you can import anything missing one at a time, the same review step as a single-dive import every time.
